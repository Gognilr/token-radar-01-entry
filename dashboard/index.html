How the value is built

Implied value follows only from the snapshot's own figures — TVL, seven-day growth, how long the protocol has run with no token, and how many chains it runs on. No protocol name is ever special-cased.

implied = TVL × 0.30
        × (1 + clamp(7d %, −50, 150) / 100 × 0.6)
        × (0.7 + min(age, 1460) / 1460 × 0.3)
        × (1 + 0.015 × min(chains − 1, 12))

A protocol with no reported 7-day change reads as 0% growth; one with no listing date reads as 365 days old. “Records no token” is what the snapshot says — a protocol on the list may still have a token its DefiLlama record does not carry.

What counts as pre-token here

A protocol is ranked when its record carries no market cap, no CoinGecko id and no symbol, and it is not a wrapped, staked or bridged product of a token that already trades, not an exchange, and not a versioned pool of another protocol — the same exclusion rule the snapshot's watchlist was drawn with, applied to every protocol so the early finds below the $50M floor are held to the same standard. The watchlist is the floor, never the ceiling: this board carries all 40 of its protocols plus every other rankable pre-token protocol in the snapshot.
